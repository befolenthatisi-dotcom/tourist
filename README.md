# Explore Lesotho

Explore Lesotho is an interactive tourism web application developed using React.js. It helps visitors discover tourist attractions, activities, and cultural experiences in Lesotho.

## Features

- **Home Page:** Introduces Lesotho and displays featured destinations and popular activities.
- **Attractions Page:** Displays nine tourist destinations.
- **Search and Filter:** Allows users to search for attractions by name and filter by category.
- **Attraction Details:** Displays detailed information about selected attractions in a modal.
- **Enquiry Form:** Allows visitors to submit enquiries about their trips.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.

## Technologies Used

- React.js
- JavaScript (ES6+)
- React Router DOM
- HTML and JSX
- CSS3
- Git and GitHub


## Getting Started

### Prerequisites

- Node.js
- npm

### Installation
   
1. Navigate to the project folder:

 bash
   cd tourists-app
  
2. Install dependencies:

  bash
   npm install
  
3. Start the application:

   bash
   npm start
   

The application will run at `http://localhost:3000`.

## Conclusion

Explore Lesotho provides an interactive platform for discovering tourist destinations and planning visits to the Kingdom in the Sky. The project demonstrates the use of React components, state management, routing, event handling and responsive web design.
